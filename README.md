# Bharat Project Connect — Website

A responsive, static multi-service business website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content and page structure
- `style.css` — layout, colours, responsive design and animations
- `script.js` — mobile navigation and WhatsApp enquiry form

## Publish with GitHub Pages
1. Sign in at https://github.com/
2. Create a **Public** repository named `bharat-project-connect`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub will show your published website address in the Pages section.

## Before publishing
- Confirm the phone number and email in `index.html` and `script.js`.
- Add your official logo and real company address if applicable.
- Review all service descriptions to ensure they accurately describe the services you provide.
- The enquiry form opens WhatsApp with a pre-filled message. It does not save submissions to a database.
- For a custom domain, configure it later in GitHub Pages settings and update your domain DNS.

## Notes
This is a static front-end website. An admin dashboard, secure login, database, file uploads, payment gateway and automatic lead storage are not included in this first version.
